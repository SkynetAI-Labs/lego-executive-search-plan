# LEGO Group | VP of Digital Play: an executive search plan
Case study by Adam Baig. Streamlit app.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`
Deploy: push app.py, content.py and requirements.txt to a GitHub repo (e.g. lego-executive-search-plan), then on share.streamlit.io choose the repo, main file app.py.
